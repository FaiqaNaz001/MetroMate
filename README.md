MetroMate - An unofficial route recommentdation chatbot to navigate around Doha using Metro and Lusail Tram. 

Initial public release of MetroMate.

Features:
- Route finding across Doha Metro and Lusail Tram
- Landmark search
- AI-powered travel assistant
- Streamlit web interface
- Responsive deployment on Streamlit Community Cloud

Known limitations:
- Route and time estimates are approximate
- Future versions will include additional transit intelligence and UI improvements
